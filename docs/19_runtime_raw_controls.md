# α6500 0x1df RAW 对照实验分析（2026-09-05）

> 目的：通过"全黑 vs 亮画面 vs ISO/快门变化"对照，判定 0x1df 缓冲是否为
> 真实场景的 Bayer RAW，还是固定/测试/未初始化数据。
> 结论：**否定**。0x1df 抓到的是高度模式化数据，非真实拍摄图像。

## 1. 抓取记录

用 `0x1df`（48MB @ 0xa6000000）缓冲，触发后抓前 16MB。

SD 卡 / 工作区 `experiments/runtime/20260905_a6500_raw_controls/`：

| 文件 | 大小 | 抓取时刻 | 备注 |
| --- | --- | --- | --- |
| RGM0.BIN | 16777216 | 22:33:00 | 全黑/极暗基线 |
| RGM1.BIN | 16777216 | 22:33:33 | 亮画面 |
| RC0.BIN | 16777216 | 22:23:30 | 较早一次亮帧 |
| RC1.BIN | 16777216 | 22:23:49 | 与 RGM0 相同 |

## 2. 判定结果

### 2.1 三重文件逐字节一致（铁证）
- RGM0 / RGM1 / RC1 主体像素 mean=172, p05=126, p50=128, p95=384, std=105，
  且**两两 mean_diff = 0.0**（逐字节完全相同）。
- 真实拍摄的 3 次快门（即便同场景）不可能逐字节一致 → 这 3 次抓取返回的是
  **同一块固定内存**，未随快门刷新为真实图像。
- RC0 是唯一不同文件：mean=23927, std=10292 → 有实际内容的"亮帧"。

### 2.2 RC0 内容高度模式化，具体来源未证实
- `0x5555`（十进制 21845 = 二进制 01010101 01010101）占 **33%**，且大量值围绕
  0x5555（21847/21853/21877/21781/20821...）。
- 该分布是强模式化数据特征；它不符合当前要验证的自然场景 Bayer 解释，但仅凭 0x5555 不能确定是传感器测试图案。
- 结合此前 0x1df 逐步分析：离散阶梯值、奇偶行分离(R-G1 corr=1.0)、行内唯一值少
  → **数据是高度模式化的结构，非自然图像 Bayer**。

## 3. 证据分级

| 结论 | 等级 |
| --- | --- |
| 拍照 RAW 路径触发 0x1df（48MB @ 0xa6000000）瞬态分配 | 已证实 |
| 0x1df 可被 /dev/mem 抓取 16MB 并取回 | 已证实 |
| 多次快门抓到的主体像素相同（RGM0/RGM1/RC1 逐字节一致） | 已证实 |
| RC0 含 33% 的 0x5555 + 大量围绕值（强模式化特征） | 已证实 |
| 0x1df 是真实场景的 Bayer RAW 图像 | **否定** |
| 0x1df 是固定/测试/未初始化类缓冲之一 | 高可信推测 | 具体来源仍未证实 |

## 4. 可能原因

1. **抓取窗口不正确**：0x1df 可能是 RAW 处理前的"原始帧缓冲"，但实际像素数据
   在别的偏移/地址，或抓取前 16MB 恰好是头部/固定模式区而非有效像素。
2. **缓冲内容未触发**：单张拍照的 RAW 数据可能不落在 0x1df，或 0x1df 是
   DFE/测试相关的寄存/采样缓冲，不是最终像素。
3. **0x5555 是传感器测试/坏点/Bayer 校验图案**：工厂测试或内部自检数据。

## 5. 下一步建议

1. **换抓取地址**：不只抓 0x1df，抓完整的 48MB，或测 0x236/0x23e/0x2b3 是否
   在拍照时出现并含真实像素。
2. **抓更大窗口**：0x1df 前 16MB 是固定模式，真实像素可能在中后段。
3. **用 stream2/DMA 通道**（docs/13）理解实际像素缓冲的映射，不要只从 DMM
   unit type 猜。
4. **确认画面差异**：若真 RAW，RGM0(黑) 与 RC0(亮) 的亮度分布应系统性差异
   （黑≈黑电平，亮≈信号），但当前两者是"固定黑帧" vs "测试图"，不符合图像。
5. 重新审视：α6500 拍照 RAW 是否走其他缓冲类型（0x236/0x23e/0x2b3），
   0x1df 可能是 DFE 2-pass / 测试专用。
