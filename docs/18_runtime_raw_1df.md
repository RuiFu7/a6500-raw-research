# α6500 实机抓到 RAW 主缓冲 0x1df（2026-09-05）

> 里程碑：在拍照 RAW 路径下，DMM 中出现了 RAW 主缓冲类型 `0x1df`，
> 并成功用 `/dev/mem` 只读抓取 16MB 到 SD 卡取回分析。

## 1. 触发与抓取过程

1. 相机开机，Zadig 把大容量存储设备（`VID_054C&PID_0AC4`）装回 libusb-win32，
   再跑 `pmca-console serviceshell` 进入服务模式、进 BusyBox shell。
2. 用户在相机按一次快门（RAW 拍照）。DMM 检测到 `0x1df` 单元出现：
   - 类型 `0x1df`，物理地址 `0xa6000000`，大小 `0x03000000`（48MB），status alloc。
   - 瞬态分配：快门后立即释放，必须边轮询边抓。
3. 边轮询边 `dd if=/dev/mem of=/android/storage/sdcard0/RW?.BIN ...`（bs=4096, count=4096
   = 16MB）。抓到 `RW0.BIN`、`RW1.BIN`（各 16777216 字节），两次快门时刻。
4. 退出服务模式 → 电脑切原生 USBSTOR → SD 卡 `F:` → 复制到
   `experiments/runtime/20260905_a6500_raw_1df/`。

## 2. 关键分析结果

### 2.1 帧间
- RW0 vs RW1 字节 diff 2.34%，集中在首块（前 30 行/头部）。主体像素几乎一致
  （98.5% 相同），符合**同一静帧两次读取**，非视频流。

### 2.2 行宽判定（决定性）
- u16 小端数据，行宽扫描（隔2行 vs 隔1行垂直差值比率）得到**唯一尖锐峰 w=3000**：
  - v2（隔2行）= 246，v1（相邻行）= 22687 → 隔 2 行差值是相邻行的 **1%**。
  - 该峰在 offset 0~8192 全部稳定成立。
- 判读：捕获窗口在 u16 解释下出现 w=3000 的结构性峰；这只能说明该解释在当前窗口最平滑，不能称为真实像素行宽。

### 2.3 位深 / 打包（重要修正）
- 12-bit MSB 打包解包后 `max=4095` 是**数学必然**，不能作为 12-bit 证据（循环论证）。
- 用"行内平滑度 ratio（相邻像素差 / 标准差）"做**客观判据**：
  | 解释 | ratio | 判读 |
  | --- | --- | --- |
  | u16 LE @ 3000 | **0.0099** | 高度平滑 = 真实空间结构 |
  | 12-bit 打包 @ 3000 | 1.2406 | ≈噪声 |
  | 10-bit 打包 @ 3000 | 1.2180 | ≈噪声 |
- 判读：u16 小端在当前窗口的平滑度启发式中优于 10/12-bit 打包；这不是位深或像素格式证明。值主体
  30k-65k，`frac<=0xFFF0=1.0`，接近满 16-bit 范围。

### 2.4 2x2 相位（Bayer 线索）
- u16 @ 3000，2x2 相位均值：R(0,0)=28788, G1(0,1)=28805, G2(1,0)=47821, B(1,1)=47814。
- 偶数行均值≈28800，奇数行均值≈47800，相差约 19000 → **强烈垂直 2 行交替结构**。
- 相位相关：R–G1 corr=1.000（同列同值），R–B corr=0.107，G1–G2 corr=0.106。
- **注意**：R–G1 完全相关(1.0)且均值相同，**不符合标准 4 通道 RGGB Bayer**
  （正常 Bayer 的 R、G 不会同值同相关）。数据实为**每 2 行交替的两种值**：
  偶数行≈3000（列内有 3197 反复出现的主导值），奇数行≈42000（列内有
  42101/42372 主导值）。列均值平滑递增（24936→25118）。

## 3. 证据分级

| 结论 | 等级 | 证据 |
| --- | --- | --- |
| 拍摄相关会话中观察到 `0x1df`（约 48MB）动态分配 | 已证实 | DMM dmm_units 实测；不等于像素内容已确认 |
| 用 `/dev/mem` 抓到 0x1df 的 16MB 数据并取回电脑 | 已证实 | SD 卡 RW0/RW1.BIN，全链路成功 |
| 数据为 u16 小端、行宽 3000 像素的**高度平滑空间结构**（ratio=0.0099） | 已证实 | 行宽扫描峰 + 行内平滑度 |
| 每 2 行交替高/低值（≈3000 vs ≈47800） | 已证实 | 行均值 + 2x2 相位分离 |
| 这是标准 RGGB 4 通道 Bayer 图像 | 未证实/倾向否定 | R–G1 corr=1.0 且同均值，不符标准 Bayer |
| 数据是某种 RAW/去马赛克前数据 | 未证实 | 只有窗口内统计结构，缺少场景响应、Bayer 和 debayer 验证 |
| 具体 Bayer pattern / 位深 / 黑电平偏移 / 场景可靠性 | 未证实 | 需场景变化、ISO/快门/V 设置对照实验 |

## 4. 下一步（确定性验证）

1. **场景变化对照**：同一 RAW 设置下拍"全黑(盖镜头)"和"亮画面"，若 0x1df 主体
   像素随 ISO/快门/场景变化且分布变化，则确认为传感器 RAW。
2. **黑电平**：盖镜头拍一张，查 0x1df 主体最小值（黑电平）与偏移。
3. **ISO 对比**：ISO100 vs 3200 各拍，观察增益（数值分布上移/拉伸）。
4. **全帧抓取**：48MB 缓冲可抓完整帧，验证 3000 像素 × 高度(约 6000px? 需确认
   传感器原始行数)，或是否含 padding/OB 区。
5. 确认奇数行 42000 / 偶数行 3000 的成因（不同通道增益 / 解交织 / 元数据行）。

## 5. 全程安全

- 仅 `/dev/mem` 只读、`dd` 写 SD、PMCA serviceshell；未写固件、未加载模块、
  未改 `/setting`、未 RAM patch。
- 驱动切换仅在电脑侧、可逆（Zadig 可装回 libusb）。
